# Compile all trials into a single datafile

This function compiles all shuttle-box trials in a list object, as
imported by read_shuttlesoft, in a single dataframe

## Usage

``` r
compile_project_data(data_read)
```

## Arguments

- data_read:

  A list object containing the imported shuttle-box trials

## Value

Dataframe of all shuttle-box trials in a shuttle-box project
